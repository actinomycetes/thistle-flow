Help and manual

Lightweight flow cytometry analysis in your browser; your data never leaves your computer. Sister app of Thistle Plot (statistics and figures). Source on GitHub.

Thistle Flow is a beta (v0.14.1). Check important results against an established package before you rely on them in a publication.

Getting started

❓ Help (or F1) opens this manual over the app; close it with ✕ Close help or Esc and your work is exactly as you left it.

  1. Click ⬆ Open FCS file(s)… (you can pick several files at once) or drag .fcs files onto the window. Files from BD FACSDiva, Attune NxT, Sony, Cytek, CytoFLEX and others are supported (FCS 2.0 to 3.2). Click 🧪 Demo data to try the app without your own files.
  2. Files in the older FCS 2 format load normally, but a message warns that they have lower resolution and dynamic range (usually 1,024 levels per channel, often log-amplified, instead of 262,144 or more in FCS 3.x): populations can look banded near zero and negative values are lost. Export them again as FCS 3.0/3.1 if you can.
  3. Drag the ☰ handle of a sample to change the order of the samples. The order is used in Statistics, batch figures and overlays, and is saved with the workspace.
  4. Starting plots appear: FSC-A vs SSC-A (cells), FSC-A vs FSC-H (singlets) and, if the files have a time channel, Time vs SSC-A (to check the acquisition was stable). Click a sample in the left pane to make it the active sample that the plots show.
  5. Draw gates (see Gating). Gates apply to every sample in the workspace, so you gate once and read the results for all samples in the Statistics tab.

You can resize the left pane by dragging its edge, and resize the Samples and Gates lists by dragging the bar between them. Double-click a divider to reset it. Use 🌙 / ☀️ in the header to switch between dark and light mode (dark is the default, as in Thistle Plot). Exports always use a white background.

Workspaces and tabs

🗑 Clear removes all samples from the current workspace. You can keep its gates and plots (ready for the next files) or start fresh. The files on your computer are not touched.

Each tab above the main area is a separate workspace: its own group of samples with its own gates, plots, layouts and statistics. Click + to start a new workspace, for example for another experiment or panel. Double-click a tab to rename it. A dot (●) on a tab means it has unsaved changes.

When you close a tab, you are always asked whether to save the workspace first.

Gating

The Gating toolbar has two rows of named groups:

  • first row, Plots: Select (move and reshape gates and labels) or Zoom, Add plot, and how many events each 2-D plot shows;
  • first row, Gate edits apply to: All samples or This sample, with ↺ Use global gate next to it for a gate adjusted for some samples;
  • second row, Gate: the gate tools for 2-D plots (Rectangle, Polygon, Ellipse, Quadrant) and for histograms (Range, Split), Delete for the selected gate, and the Quadrant style (Standard, Spider, Offset) when a quadrant is selected.

Select a quadrant to choose its style in the toolbar: ✚ Standard (a straight cross), ✳ Spider (drag the round handle on each arm to turn it to its own angle, for tilted or diagonal populations) or ⌗ Offset (drag the round handle on each arm to slide it on its own, so the upper and lower halves, or the left and right halves, can have different cut-offs). The four quadrants always cover every event exactly once. Dragging the centre moves the whole quadrant.
Range IOn a histogram, drag across the range.
✨ Auto AClick inside a population (a cluster of events) on a 2-D plot: a polygon gate is drawn around it, following the density of the events and stopping where the population meets a neighbouring one. While the tool is on, the outline follows the cursor so you see what you will get. Shift-click makes a tighter gate around the core. The result is an ordinary polygon: check it and drag its corners if needed. Events piled up on the axes (off scale) are not used to find populations.
Split SOn a histogram, click where to divide it. Two linked gates are made: left (e.g. CD3-) and right (CD3+). They always add up to the parent. Drag the line to move both; click one side to select it.

After you name a gate, the tool switches back to Select V. In Select mode you can:

  • move a gate by dragging inside it, and reshape it by dragging a corner or handle;
  • move a gate's label by dragging the label. Labels stay inside the plot, and their position is saved with the workspace;
  • double-click inside a gate to open a plot of that population, or double-click a label to rename the gate;
  • delete the selected gate with Delete.

Zooming in

Choose 🔍 Zoom Z and drag a box over the area you want to see (on a histogram, drag across a range). The plot then shows only that area, with axis ticks for the zoomed range. Zoom stays on, so you can drag again to zoom further, until you choose Select (or another tool). Double-click a plot while Zoom is on to reset it (the same as ⤢). Zooming changes only the view: gates, percentages and statistics are unchanged, and you can still draw and adjust gates while zoomed in. Zoomed plots show ↩ (Unzoom, back to the previous view) and ⤢ (Reset zoom, the whole axis) in their header. Changing a plot's channel resets its zoom. The zoom is saved with the workspace and included in exports.

Adjusting a gate for one sample

Gates are shared by every sample. When a sample needs a slightly different gate (for example a shifted population), set Gate edits apply to in the toolbar to This sample. Moving or reshaping a gate then changes it only for the active sample; quadrant centres, arms and style change for all four quadrants of that sample. Switch back to All samples to edit the shared gate. If you adjusted gates while in This sample, switching back asks what to do:

  • Apply to all samples: the adjusted version becomes the shared gate for every sample;
  • Keep for … only: the adjustment stays that sample's own (marked ✎);
  • Cancel: stay in This sample.

If gates were adjusted for several samples, “Apply” uses the version of the active sample.

  • How adjusted gates are marked: drawn with a dashed outline and ✎ after the name on the plot label; ✎ with the number of adjusted samples in the gate tree (hover to see which); a ✎ gates badge on the sample in the sample list.
  • Going back: select the gate and click ↺ Use global gate. If other samples are also adjusted, you can choose this sample only or all of them.
  • Statistics, batch figures and exports use each sample's own gate. Changes to the shared gate do not move a sample's adjusted gate.
  • Adjustments are saved with the workspace (linked to the file name). Templates contain only the shared gates. Adjustments can be undone in the Gating tab.

Dragging a gate edge onto an axis extends the gate past the axis, so off-scale events piled on that axis are included.

Plot types and settings

Choose the type in the plot header or in the plot's ⚙ settings:

  • Pseudocolor: every displayed event as a small dot coloured by local density (blue = sparse, red = dense).
  • Density: a smoothed density map.
  • Contour: equal-probability contour lines. With the 10% step, each line encloses 10% fewer events. Events outside the outermost line are shown as dots, which you can turn off under Outliers.
  • Dot: plain dots.
  • Histogram: set Y to “— Histogram —”.

Events shown. Busy plots can be thinned out. The Show … events/plot menu in the toolbar sets the default for the workspace (10,000 at first). Any plot can override it in ⚙ → Events shown. The same subset of events is always shown, so a child population shows a subset of its parent's dots. Statistics and gate percentages always use every event.

Size. Choose S, M, L or XL in ⚙. Dot size (⚙, and in Layout figures) makes the event dots smaller or larger, from Tiny (0.8 px) to Extra large (3 px).

Quick overlay of several samples

In the sample list, Ctrl-click (⌘-click on a Mac) samples to add or remove them, or Shift-click to select every sample between the current one and the clicked one. With two or more samples selected, every Gating plot overlays them:

  • 2-D plots show each sample as coloured dots;
  • histograms are overlaid and normalised to their mode;
  • gate labels list each sample's %.

Each sample's colour is also shown as a swatch in the sample list. Gates can still be drawn and adjusted, and they apply to all samples as usual. A plain click on a sample, or Show one sample in the toolbar, goes back to one sample. For a figure to keep or export with its own settings, use the Layout tab.

Changing several plots at once

Select several plots, then change any setting in one of them (population, axes, type, events shown, size). The change applies to every selected plot.

  • Shift-click a plot (its header or an empty part of the plot) to add or remove it from the selection.
  • Drag a box on the empty background around plots to select them. Hold Shift to add to the current selection.
  • Ctrl+A selects all plots. Esc clears the selection. Delete closes the selected plots when no gate is selected.

Axis scales

Click an axis (its tick labels or title) to open a quick menu for that axis of that plot only. It lets you change the channel shown on the axis (or switch Y to a histogram) and the scale of that channel: Linear, Log, Biex(ponential) or Arcsinh, with its range or width. The menu opens just outside the plot next to where you clicked (to the left for the Y axis, below for the X axis, or to the right when the plot is at the bottom of the window), so you can watch the change; click Done (or anywhere outside the menu, or press Esc) to close it. ⚙ → X axis… / Y axis… opens the same menus, and if several plots are selected, a channel change applies to all of them. Axis scales in the Plots group of the Gating toolbar is the full dialog for any channel. The choices are Linear, Log, Biexponential (Logicle) and Arcsinh.

Scales belong to a channel, not to one plot, so a gate always means the same events wherever it is shown. For the biexponential scale, Auto W estimates the width from the negative events of the active sample. Increase W if compensated negatives look squashed against zero.

Compensation

The spillover matrix stored in each file ($SPILLOVER, SPILL) is read and applied automatically. The Compensation tab (next to Gating) shows it for each sample: edit it, apply it to all samples, or import or export it as CSV. Edits you have not applied yet are kept while you switch tabs, and applied changes can be undone with ↶ Undo in this tab. Spectral instruments (Sony ID7000/SA3800, Cytek) usually export data that is already unmixed. Thistle Flow cannot unmix raw spectral data.

Adjusting the matrix with the preview plots

Next to the matrix, the Compensation window shows a grid of small preview plots, one for each value in the matrix and in the same place: the plot in row A and column B shows channel A (X) against channel B (Y), the pair that the value “A into B” corrects. A larger plot with axes shows the selected value. Click a value or a plot to select it, then type a new value or nudge it with ↑ / ↓ (0.001; with Shift 0.01, with Alt 0.0001). The plots are redrawn as you edit, but nothing changes in your samples until you click Apply (“● Edited: not applied yet” reminds you); ↺ Reset edits goes back to the applied matrix.

  • Cells stained only with dye A should lie flat in channel B, level with the unstained cells. If they slope up, too little is subtracted: raise the value. If they bend down below the unstained cells, too much is subtracted: lower it. The dashed lines mark zero.
  • Preview chooses the population shown (for example Singlets, or a single-stained control) and the number of events; Uncompensated shows the raw data for comparison.
  • Gates are not redrawn in the preview; after applying, check the gated populations in Gating.

Layouts and overlays

  • Histogram overlay: any combination of sample and population. The Y scale can be normalised to mode or count. Offset options:
    • Overlay: histograms on top of each other;
    • Quarter and Half offset: staggered, partly overlapping;
    • Full offset: stacked with no overlap;
    • Custom: set the offset with a slider.
  • Dot-plot overlay: series coloured by sample or population.
  • Batch: the same plot for every sample, with gate percentages.
  • Gating strategy: the path to one population for one sample, as a row of plots joined by arrows: All Events with the first gate (e.g. Cells), then that population with the next gate (e.g. Singlets), and so on down to the population chosen in Down to. Each plot shows only the gate on the path (tick Other gates too to show the others); quadrant and split gates show all their parts. Then show adds a last plot of the final population on channels of your choice (or a histogram). Choose the Sample; the figure uses that sample's own gates if they were adjusted for it.

Population, above the series list, sets the gate of every series in one go, for example Singlets for all samples. Each series keeps its sample and colour, and you can still change a single series in its row. If the series use different gates, the menu shows “— different per series —”. All samples makes one series per sample using that population. Change a figure's size with W and H; with Keep ratio ticked (the default), changing one also changes the other so the figure keeps its shape. Child gates makes one series per subpopulation.

Gating all samples from a histogram overlay

Click ↔ Range gate in a histogram overlay's settings and drag across the histograms. One gate is created and, because gates are shared by every sample in the workspace, it applies to all samples at once. The label lists each sample's % in its series colour. Drag the gate's ends or bar to adjust it, and double-click the label to rename it. The new gate also appears in the gate tree, in Gating plots and in Statistics. The series must all use the same population, which becomes the gate's parent. The gate belongs to the Gating history, so undo it from the Gating tab (or delete it with Delete).

Sample labels and legends

In histogram and dot-plot overlays, Labels controls the sample names (one per histogram when they are offset, otherwise a legend):

  • In the plot: drag a label or the legend to move it;
  • Outside, right: the labels sit to the right of the plot, which narrows to make room, so they never cover the data;
  • Off: no labels.

Gate labels hides the gate labels of a figure. Reset label positions puts every label of the figure back in its default place.

Moving labels in figures

Drag any gate label in a Layout figure to move it, as in Gating. Each figure keeps its own label positions, so arranging a figure does not move the labels in your Gating plots. In a batch figure, moving a label in one sample's plot moves it in all of them. Label moves can be undone in the Layout tab.

Statistics and MFI

Tick the populations, statistics and channels you want: Count, % Parent, % Total, Median (MFI), Mean, Geometric mean, SD, CV, Robust SD and Robust CV. There are three table layouts:

  • long: one row per sample and population, best for R and Prism;
  • wide: one row per sample;
  • transposed: one column per sample.

Use Export CSV… or Copy. Values are computed on compensated data, without the display transform. The geometric mean uses positive events only.

Properties (acquisition info)

The Properties tab, also opened from the ⓘ button next to a sample, shows:

  • information read from the file: instrument, serial number, software, date, start and end times, duration, operator, experiment, specimen or tube, plate or well, volume, lasers and compensation;
  • a channel table: marker labels, voltages, filters and lasers;
  • every keyword in the file, with a search box.

Editing: click a value to change it. You can also rename the sample, fix marker labels (and copy them to all samples with Apply labels to all samples), and add keywords. Edited values are highlighted.

  • Edits are stored in the workspace and can be undone. They are also written into FCS files you export from the gate tree.
  • The original files are never modified.
  • Keywords that describe the data layout (byte order, data type, bits, range and so on) are read-only.

Export summary CSV writes one row per sample with the acquisition fields, which is useful for lab records.

Saving: workspaces and templates

💾 Save workspace Ctrl+S opens a dialog where you can choose the file name. The name starts with the workspace name plus the date and time, so earlier saves are not overwritten. In Chrome and Edge you then choose the folder. Other browsers save to the Downloads folder, or ask where, depending on their settings.

  • A workspace stores gates, scales, plots, layouts, statistics settings, compensation and metadata edits. Tick Include the FCS files (the default) to save everything as one .zip file that reopens with all its samples with 📂 Load workspace. The .zip is an ordinary zip file: workspace.json plus the original, unmodified FCS files in fcs/.
  • Without the FCS files the workspace is a small .json. When you open it, a dialog lists the missing samples. Browsers cannot open files next to the workspace by themselves, so click 📂 Choose folder… and pick the folder with the FCS files; every file with a matching name is loaded. You can also use Choose files…, or Choose… on a row to assign a file with a different name. Loading the FCS files first and then the .json also works.
  • ⇄ next to a sample replaces its FCS file (for example a re-exported or renamed file) and keeps the gates, figures, compensation and edits. Channels missing from the new file are reported.
  • A template (📋 Save template) stores the same analysis settings with no sample data and no file names. You can optionally include a compensation matrix and marker labels. Use 📥 Apply template in any workspace to reuse a gating strategy on new samples. You can undo it.

Exporting PNG, SVG and PDF

Each plot's ⤓ menu and each figure's Export ▾ menu offer:

  • PNG: high resolution, about 300 dpi;
  • SVG: vector, for Illustrator or Inkscape;
  • PDF: vector.

Export layout ▾ exports all figures in the Layout tab as one file.

In SVG and PDF, the axes, text, gates, contours, histograms and dots are vector shapes. Pseudocolor and density shading is embedded as an image. ⤓ in the gate tree exports the events of a population as a new FCS file.

Undo and redo

Each mode (Gating, Compensation, Layout, Statistics, Properties) has its own undo history, so undoing a layout change never undoes a gate. Use ↶ Undo / ↷ Redo at the right of the mode tabs, or Ctrl+Z / Ctrl+Shift+Z (Ctrl+Y). Gating covers gates, plots and axis scales; Compensation covers the matrices and the compensation on/off switch. Loading or removing samples is not undoable.

Known limitations of v0.14.1 (beta)

  • Gates are shared by all samples in a workspace. There are no per-sample gate adjustments yet.
  • FlowJo .wsp and Gating-ML files cannot be imported. There are no derived parameters and no tSNE/UMAP.
  • Raw spectral data cannot be unmixed.
  • Thistle Flow is beta software. Check important results against an established package before publishing.
